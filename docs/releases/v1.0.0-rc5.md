## Fixed

- **World map pop-in in widescreen.** Location symbols such as cave entrances are drawn as they enter the wider view on either side of the screen.
- **Black bars during the ending flyover.** The sky backdrop now fills the widescreen view as the camera turns.

Both fixes were checked in Vita3K. Verification of the fixes on a physical Vita is pending.

## Installation

- To update from a previous release candidate, install the new **dqivn.vpk** over the existing app. You can keep your converted game data and saves in `ux0:data/dqiv/`.
- For a new installation, follow the [installation guide](https://github.com/frangarcj/dqiv_vita#installation).
