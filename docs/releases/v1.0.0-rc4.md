## Fixed
- **Crash with the Map button in the Chapter 2 Colosseum.** Pressing Square (Map) in a place that shows a shop list but has no town map, such as the Colosseum, crashed the game if a map had been opened earlier (the world map or a town map). The bug is in the original game code: closing a map left it half-open, and the shop list then used it. It is now fully closed, and the shop list opens normally.

## Status
- The fix comes from a tester's crash report on a real Vita (rc3). The crash was reproduced in the Vita3K emulator and the fix was checked there, **not yet on a real Vita**. All 32 scripted test scenarios (towns, shops, inn, church, battles, world map, and a new one for this crash) ran on an optimised build again.
- Sound has never been checked by ear. Most of the story has not been played through by the developer.
- Korean and Chinese text, and performance and memory during long play on a real console, are unverified. Expect bugs, and keep backups of your saves.

## Installation
- Updating from rc1, rc2 or rc3: install the new **dqivn.vpk**. Your converted data and saves in `ux0:data/dqiv/` stay as they are.
- New install: install **dqivn.vpk**, [kubridge](https://github.com/bythos14/kubridge/releases/) and [FdFix](https://github.com/TheOfficialFloW/FdFix/releases/) (skip FdFix if you already use rePatch). Convert your own **Google Play v1.0.5 APK and OBB `main.106`** with the [web converter](https://frangarcj.github.io/dqiv_vita/) or `tools/make_data.py`, then copy the result to `ux0:data/dqiv/`. See the [README](https://github.com/frangarcj/dqiv_vita#installation) for the full steps.
