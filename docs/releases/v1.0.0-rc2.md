## Fixed
- **Crash at the start of battles.** With the default landscape battle view (`battle_layout=large`), v1.0.0-rc1 could crash a moment after a battle opened. If you installed rc1, please update.
- **Dark boxes flashing over the party portraits.** In battle, members without an action label (for example under direct control) could show a dark box over their portrait for a single frame.

## Status
- Both fixes were checked in the Vita3K emulator, **not yet on a real Vita**: the crash came from a user's report on real hardware and could be reproduced in an emulator build with the same memory layout. All 31 scripted test scenarios (towns, shops, battles, world map) also ran on an optimised build this time, without a crash.
- On a real Vita, this build has not been played. So far only the start-up has been checked by the developer, and sound has never been checked by ear. The prologue and most of the story have not been played through.
- Korean and Chinese text, and performance and memory during play on a real console, are unverified. Expect bugs, and keep backups of your saves.

## Installation
- Updating from rc1: install the new **dqivn.vpk**. Your converted data and saves in `ux0:data/dqiv/` stay as they are.
- New install: install **dqivn.vpk**, [kubridge](https://github.com/bythos14/kubridge/releases/) and [FdFix](https://github.com/TheOfficialFloW/FdFix/releases/) (skip FdFix if you already use rePatch). Convert your own **Google Play v1.0.5 APK and OBB `main.106`** with the [web converter](https://frangarcj.github.io/dqiv_vita/) or `tools/make_data.py`, then copy the result to `ux0:data/dqiv/`. See the [README](https://github.com/frangarcj/dqiv_vita#installation) for the full steps.
